# Cockpit · redesign visual

Protótipo navegável do novo visual do OpenFlows Cockpit, seguindo o manual de marca e o Design System da designer.

- Só visual: nenhum dado real, nenhuma chamada ao backend. Números, conversas e status são de exemplo.
- Abra `index.html` servindo a pasta (ex.: `python -m http.server`); as fontes não carregam por `file://`.
- Telas: Projetos, Conversas, Chat (arquivos com preview, terminal, GitHub), Agentes (organograma) e Planos. Tema claro e escuro em Ajustes.

Teste temporário. Nomes de clientes e pessoas são fictícios. As fontes Intrade e Duplet Open são licenciadas para a OpenFlows; apague este repositório depois do teste.
